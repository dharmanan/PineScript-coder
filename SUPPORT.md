# Support

## Where to ask

- **Questions and usage help:** open a GitHub Discussion.
- **Reproducible bug:** use the bug report issue form.
- **New preset or product idea:** use the preset idea issue form.
- **Security concern:** follow [SECURITY.md](SECURITY.md). Do not post sensitive details publicly.

## Include useful context

For a useful answer, include the Studio preset or configuration, chart timeframe, relevant input values, the generated Pine Script version and steps to reproduce the behavior. Remove API keys, account details and any sensitive data first.

Kohen Pine Studio is an open-source project maintained in available time. Responses are best-effort and do not constitute investment, legal or financial advice.
